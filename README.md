# 🚀 JavaScript_Intro

Guía básica de introducción a JavaScript enfocada en los fundamentos esenciales del lenguaje: **variables, constantes y tipos de datos**.

---

## 📌 Descripción

Este repositorio contiene ejemplos simples y claros para comprender los conceptos básicos de JavaScript, ideal para estudiantes de nivel inicial o bachillerato técnico.

Los archivos están organizados por temática para facilitar el aprendizaje progresivo.

---

## 📂 Estructura del proyecto

---

## 🧠 Contenidos

### 🔹 intro.js
- Primer contacto con JavaScript
- Uso de `console.log()`

### 🔹 variables.js
- Declaración de variables con:
  - `let`
  - `var` (uso básico)
- Asignación de valores

### 🔹 constantes.js
- Uso de `const`
- Buenas prácticas
- Variables inmutables

### 🔹 tipodatos.js
- Tipos de datos primitivos:
  - String
  - Number
  - Boolean
  - Null
  - Undefined

---
